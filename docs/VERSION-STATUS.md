# Mi Lugar — Estado oficial de versión

**VERSIÓN VIGENTE: 1.4**  
**NOMBRE:** CAPA VISUAL CONSOLIDADA

## Fuente única de verdad

Este documento identifica la versión vigente del proyecto.  
Si otro documento histórico menciona una versión futura o una etapa anterior, debe interpretarse como registro histórico y no como estado actual.

## 1. Qué está congelado

- `index.html`
- `js/app.js`
- navegación pública
- flujo de uso
- estructura de secciones
- arquitectura pública
- destino GitHub Pages
- decisión de no utilizar Vercel

## 2. Qué está activo dentro de 1.4

La versión 1.4 permite profundizar únicamente:

- diseño visual
- fotografía real y tratamiento editorial
- ilustración
- color y textura
- composición
- responsive
- calidad, corrección y trazabilidad del contenido
- coherencia visual del conjunto

## 3. Qué ya forma parte de 1.4

- identidad territorial consolidada
- fotografía real como protagonista
- mapa territorial como pieza visual
- tratamiento de postales y archivo
- mirada local editorial
- mensajes de cuidado del lugar
- prioridad visual: territorio → memoria → comunidad → actividad comercial
- sistema visual responsive
- documentación de versión consolidada

## 4. Qué NO significa 1.4

1.4 no es una nueva aplicación ni una nueva arquitectura.

No habilita:
- nuevas funciones por cantidad
- cambios de navegación
- cambios del flujo
- Vercel
- reemplazo del núcleo funcional
- crecimiento de interfaz sin justificación

## 5. Antecedentes

- **1.0:** base funcional congelada.
- **1.4:** estado público vigente y consolidación visual.

La numeración intermedia queda absorbida por la evolución del proyecto y no constituye estados públicos independientes mientras no exista documentación específica de cierre.

## 6. Próxima etapa

Hasta una nueva orden de versión, todo trabajo continúa dentro de **1.4**.

Una futura versión solo existe cuando sea creada y documentada explícitamente. No se debe anticipar una “Versión 2” como si ya estuviera vigente.

## Regla final

> **Si no dice 1.4, no es el estado vigente. Si dice 1.0, es antecedente histórico.**
