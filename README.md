# Mi Lugar — San Patricio del Chañar

Proyecto turístico, cultural y territorial independiente dedicado a descubrir San Patricio del Chañar desde una mirada cercana, visual y profundamente documentada.

## Principio rector
**Simple por fuera. Profundo por dentro.**

La persona visitante debe poder entender el sitio en segundos. La arquitectura interna debe permitir crecer durante años sin convertir la experiencia en una base de datos difícil de usar.

## Dirección
- Turismo de territorio, no portal de noticias.
- Cercanía local, sin tono institucional obligatorio.
- Fotografía real + ilustración editorial + color.
- No videojuego.
- No estética bancaria/corporativa.
- Mobile first.
- Contenido verificable y trazable.
- Cada contenido debe poder compartirse de forma individual.
- GitHub Pages como destino de publicación. No Vercel.

## Estructura inicial
- index.html — experiencia pública.
- css/ — sistema visual.
- js/ — motor de navegación y contenido.
- data/ — contenido territorial estructurado.
- docs/ — constitución, arquitectura y reglas.

## Regla de crecimiento
No agregamos funciones por cantidad. Cada nueva capa debe aumentar la capacidad de conocer, recorrer, comprender o valorar el territorio.

## Autoría
Proyecto independiente de documentación y puesta en valor de San Patricio del Chañar.
